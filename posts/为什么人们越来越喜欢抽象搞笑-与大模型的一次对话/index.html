为什么人们越来越喜欢抽象搞笑？—— 与大模型的一次对话

Feb 7, 2026 00:00 · 4655 words · 10 minute read
Table of Contents

前几天和 Cursor 里的 AI 聊了聊「抽象」和「无厘头」、为什么现在的搞笑越来越难解释、以及它和传统「情理之中意料之外」的段子有什么不同。下面是完整对话，原样保留。

我在想一个问题。我们一起来讨论一下，为什么现在的人都越来越喜欢抽象的东西？而且不光光是中国，别的国家也是一样。国内的例子，人们开始喜欢很抽象的搞笑，我突然想到是不是以前也是喜欢的？像是周星驰的电影，只不过那时候不叫抽象，叫无厘头。但现在人们喜欢的东西越来越抽象，当然视频里的搞笑可能也放大了这一点。
Cursor

这个问题挺有意思，可以分几块来看。

1. 「抽象」和「无厘头」是不是一回事？

有联系，但不完全一样。

  • 无厘头（周星驰那种）：逻辑跳、梗密、夸张，但多数还是有「情节 + 人物 + 一句能复述的梗」。笑点往往还能用一句话讲清楚。
  • 现在的「抽象」：更依赖氛围、节奏、表情、重复、荒诞感，很多笑点在于「说不清为什么好笑」——一旦解释，反而不好笑了。所以「抽象」里「不可言说」的那部分确实比无厘头更强。

所以可以说：无厘头是逻辑上的荒诞，抽象是意义和解释上的悬空——后者更「抽象」一点。

2. 为什么大家会越来越吃「抽象」这一套？

可能和这几件事有关：

  • 信息过载 梗和解释太多，大家反而烦「又要讲道理、又要升华」。抽象搞笑不用解释、不用总结，省认知，也避免「被教育」的感觉。

  • 对「正经叙事」的疲劳 广告、短视频、营销都在讲故事、上价值。抽象的东西不假装有意义，反而显得真实、不装，容易让人放松。

  • 媒介变了 短视频几秒就要抓住人，表情、语气、节奏、重复比完整故事更好用。抽象正好适合这种碎片化、氛围化的表达，所以会被算法和传播放大。

  • 身份与圈层 「懂这个梗」本身变成一种认同。抽象梗往往没法向圈外人解释，所以天然适合做圈内暗号，越抽象越有「我们才懂」的感觉。

所以不一定是「人类突然更喜欢抽象」，而是环境（信息、媒介、疲劳感）让抽象类内容更容易被看到、被喜欢。

3. 以前是不是也喜欢？只是不叫「抽象」？

有道理。无厘头、冷幽默、荒诞剧、达达、某些先锋艺术，一直都有「不讲道理、只玩感觉」的一脉。

区别可能在于
  • 以前：这类东西更多在电影、剧场、小圈子里，名字是「无厘头」「荒诞」「实验」。
  • 现在：同样那种「不讲清逻辑、只玩氛围」的东西，被短视频、弹幕、二创大量生产，被统一叫成「抽象」，而且体量特别大，所以显得「现在的人特别喜欢抽象」。

所以：喜欢的心理可能一直有，变的是数量、媒介和名字。

4. 视频是不是放大了这一点？

是的。短视频的特点就是：

  • 短，没法展开完整逻辑 → 适合氛围、节奏、表情。
  • 重复、鬼畜、梗化 → 意义被抽空，只剩「感觉」。
  • 算法推相似内容 → 抽象风格一旦跑通，就会越推越多。

所以「抽象」不一定是人类本性变了，而是特别适合当前这种短视频 + 算法的环境，被放大成了主流口味之一。

总结一下
无厘头更像「荒诞但有梗可讲」，现在的抽象更像「连梗都懒得讲清楚，好笑在感觉」。大家未必是「从不喜欢到喜欢抽象」，而是一直有人喜欢这种不讲道理的好笑，只是现在环境让这类内容更多、更显眼，并且被统一叫成了「抽象」。你要是愿意，我们可以再具体聊聊：你心里「抽象」和「无厘头」各有一个代表作品或博主吗？可以对着例子细拆。
无厘头的代表当然是周星驰，他的电影里的很多场面都是很无厘头的很荒诞的。现在的无厘头，我前些天看的影视飓风的视频里，他们的搞笑就是很抽象的。另一个以抽象闻名的视频博主是金广发，他的视频我都没法跟别人介绍，如果别人知道就是知道，不知道我也没法解释。因为我很别人介绍过一次金广发的视频，但她就完全无法理解，她只觉得看不懂，整个视频看完都不知道视频在表达什么，我说那就是抽象，他的视频里也有一些固定的东西，比如金广发喜欢喝水。类似的事情是前一段时间一个朋友很惊讶我居然不知道哈基米南北绿豆，我说我确实不知道，那你跟我讲一下吧，他发现他也没法解释，就只好上b站找了一个介绍哈基米南北绿豆发展全过程的视频给我看。我也看过一个美国的抽象视频，一个女生去得克萨斯州，在她说的所有话里都加上了yeehoo，就是牛仔赶马的声音？应该是。

你举的这几个例子，刚好把之前说的几个点都对上了。

金广发：抽象到「没法介绍」

你说的那种体验特别典型：能看懂的人不用解释，看不懂的人怎么讲都进不去。

金广发的视频往往没有一条「主线任务」——没有要讲清楚的道理，也没有要完成的故事，就是人、动作、台词、节奏堆出来的氛围。你朋友问「这视频在表达什么」，其实问的是「意义」，而很多抽象梗的乐趣恰恰在于不负责提供这种意义。所以你会说「那就是抽象」——抽象在这里，几乎等于「不追求可被总结的主题」。

像「金广发喜欢喝水」这种固定动作/习惯，在抽象创作里特别重要：它们不解释，但会重复出现，变成一种内部符号。懂的人看到「他又在喝水」就会心一笑，不懂的人只会觉得「这人老喝水干嘛」。这种「我们才懂的细节」，就是圈层感。

哈基米南北绿豆：梗的「考古」化

你朋友发现自己也没法讲清楚，只能丢一个「发展全过程」的梳理视频给你——这说明这类梗已经复杂到：

  • 单点解释没用：必须知道时间线、出处、谁先说的、怎么变的。
  • 理解成本高：要补很多前情，才能觉得好笑。
  • 传播靠「考古」：所以 B 站会出现专门做「某某梗发展史」的 up 主。

入圈门槛变高，但一旦入圈，那种「我懂这一整套」的满足感也很强。这和金广发那种「没法介绍」是一体两面

影视飓风：从「无厘头」到「抽象」

影视飓风做的是偏专业向的内容，但他们的搞笑段落确实越来越氛围化、节奏化——少一点「一个完整笑话」，多一点冷不丁的怪、剪接的节奏、表情和反应。 这很符合我们说的：无厘头还有「一个桥段、一个梗」可以复述，抽象更依赖「那一刻的感觉」。所以同样是「不正经」，你会觉得他们现在的搞笑更「抽象」——不是周星驰那种一段戏能讲出来的荒诞，而是剪法和节奏本身在搞笑。

得州 yeehaw 视频：抽象是跨文化的

那个「女生去得州，每句话都加 yeehaw」的美国视频，结构其实和金广发、哈基米那种很像：

  • 一个简单规则：所有话里塞进 yeehaw。
  • 执行到底：越认真、越一本正经，越好笑。
  • 不解释：不告诉你「这代表什么」，就是重复 + 荒诞。

所以「抽象」不光是中文互联网的产物，而是一种当代的搞笑语法：规则简单、执行彻底、意义悬空，靠重复和氛围让人发笑。不同文化里会换上不同的符号（yeehaw、喝水、哈基米绿豆），但底层的「无意义之意义」是相通的。

你提到的这些例子，大致可以归纳成：

维度 无厘头（周星驰） 抽象（金广发 / 哈基米 / yeehaw）
能否复述 能——「那段是讲……」 很难——「就是那种感觉」
入圈方式 看一部电影就能笑 往往要补梗史、看很多条才懂
固定元素 角色、桥段 小动作、口头禅、梗的谱系
跨文化 港式无厘头有地域性 规则+重复式抽象在各地都有类似形态

所以：无厘头是「一个荒诞故事」，抽象更像是「一整套只有圈内人才接得上的符号和节奏」。你朋友看不懂金广发、你一开始不知道哈基米南北绿豆，都说明这种「知道就知道，不知道就很难被介绍进去」的边界，恰恰是抽象文化的一部分。

但是，为什么会变成这样呢？我记得以前的搞笑，就是要讲段子，或者做模仿。一些例子就是赵本山和小沈阳，还有那个时代的电影里的搞笑桥段。因为搞笑的本质是"情理之中，意料之外"的认知冲突与优越感释放。它通过铺垫正常逻辑，再进行反转打破常规，利用这种矛盾、荒谬或突然的失败带来心理上的放松和愉悦。其核心在于以幽默视角讲述真相或痛苦。 但抽象，似乎，和这个，不一样啊？
Cursor

你抓到了关键：传统搞笑和抽象搞笑，用的是两套不同的机制。

传统搞笑：你总结的那套仍然成立

「情理之中，意料之外」+ 认知冲突 + 一点优越感 + 用幽默讲真相或痛苦——这套用来理解赵本山、小沈阳、过去很多喜剧片是成立的：

  • 有铺垫：先建立「正常逻辑」或「常态」。
  • 有反转：用一句话、一个动作打破预期。
  • 有对象：往往有一个被调侃的人、一种现象、一种荒诞，观众站在「看懂了」的那一侧。
  • 可复述：笑点能变成「有个段子是这样的……」

笑来自预期被打破的那一下，以及「我懂了这个梗」的确认感。

抽象搞笑：的确和这套不一样

抽象搞笑经常
  • 没有清晰铺垫：不给你一条「正常逻辑」的线。
  • 没有标准反转：没有「就为了这一下」的 punchline。
  • 没有明确靶子：不是在笑「某个人蠢」或「某件事荒诞」，有时就是在笑「这玩意儿居然存在」「这话居然被这么认真说出来」。
  • 很难复述：你很难用「有一个段子」的方式讲给别人。

所以你说得对：它和「情理之中、意料之外」的那套不完全是一回事。

那为什么会变成这样？几种可能

1. 传统结构被「用完了」

当大家都看过无数个「铺垫—反转」的段子和小品，对结构的预期本身就变强了。 「意料之外」越来越难做——观众一看到铺垫就在等反转，反转反而变「意料之中」了。 一种应对方式就是：不做这套结构。不给你铺垫，也不给你一个明确的「就为了这一下」——笑点变成「这整件事的存在」「这节奏」「这重复」本身。 所以抽象有点像：当「反转」被预判了，就改成「不玩反转，改玩无结构」。

2. 「讲真相/痛苦」让人累

传统搞笑常带着一点任务：用幽默讲一点道理、刺一下现实、化解一点痛苦。 但当生活中到处都是「观点」「解读」「你应该这样想」时，连搞笑都在「传递信息」，会累。 抽象搞笑往往不负责讲清任何道理，也不一定「以幽默讲痛苦」，就是荒诞、重复、怪。 笑来自「不用从里面提炼意义」的轻松——从「总要听懂点什么」里逃出来。

3. 优越感换了一种形式

传统里，优越感常常是：我比段子里的那个人聪明 / 我比那个角色先看懂。 抽象里，优越感更多是：我接受「没有意义」这件事，而且还能觉得好笑—— 不是「我比谁聪明」，而是「我在这套没逻辑的符号系统里，和同好一起在玩」。 所以从「对某个对象的优越」变成了「对「非要意义」的那种期待的优越」——我们不再笑「那个人」，而是笑「还在问『这到底在讲什么』的人」那种不适感本身（有时也包括自己第一次看时的懵）。

4. 媒介在改「好笑」的节奏

段子、小品、电影桥段，需要一段时间的铺垫才能反转。 短视频、碎片观看，很难让人耐心等一个三分钟后的 punchline。 抽象更适合短平快：一个动作、一句怪话、一个表情重复几次，几秒内就有「怪」的感觉，不需要完整叙事。 所以不是「人类突然不喜欢段子了」，而是段子依赖的节奏和注意力，和当前媒介不太匹配，而抽象恰好适配。

5. 笑点从「一个时刻」变成「一种状态」

传统搞笑
笑集中在反转的那一秒。
抽象搞笑

笑分散在整段的气氛、节奏、重复、荒诞感里，没有明确的「就是这一下」。 所以「情理之中、意料之外」仍然在，但被拆碎、拉长了：

  • 你预期「视频总该有个主题吧」→ 没有，这是对「形式」的意料之外。
  • 你预期「这句话总该有下文吧」→ 没有，就停在那儿，这也是意料之外。

只是这个「意外」不再绑在一个角色、一句 punchline 上，而是绑在「整个东西竟然就这样」上。

小结：本质有没有变？

可以这么看：

  • 「打破预期」还在：只是从「打破故事里的预期」变成「打破你对「搞笑该怎么搞」的预期」。
  • 「认知冲突」还在：冲突来自「这应该有意义 / 这居然没有意义」。
  • 「优越感」形式变了：从「我比角色聪明」变成「我能待在这种无意义里还觉得爽」。
  • 「讲真相或痛苦」被弱化甚至放弃了：抽象常常故意不承担这份任务。

所以：搞笑的底层（冲突、释放、一点优越）可能还在，但实现方式变了——从「一个可复述的段子」变成「一整套氛围、符号和节奏」。 不是完全换了一个本质，而是在媒介、疲劳感、对意义的逆反之下，长出了另一种形态。 你觉得「和以前不一样」的感觉是对的；追问「为什么会变成这样」，上面这些算一种可能的解释方向。
